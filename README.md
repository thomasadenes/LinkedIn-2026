# KPI LinkedIn 2026

Tableau de bord des indicateurs des réseaux sociaux suivis dans Notion.

## Périmètre

- Publications du 1er janvier au 31 octobre 2026.
- Comparaison des évolutions d'abonnés et des formats de publication.
- Classements Top 10 / Flop 10.

## Sécurité et publication

Le site GitHub Pages est public par nature. Le projet vise à chiffrer les données exportées et à demander un mot de passe dans le navigateur. Le chiffrement ne constitue pas une authentification côté serveur et ne rend pas le site privé.

Les secrets Notion et de chiffrement doivent être configurés dans les secrets GitHub Actions et ne doivent jamais être ajoutés au dépôt.
